QUIZ BOT - SABSE AASAAN TAREEKA
===============================
1. Is ZIP ko pehle EXTRACT karo (right-click -> Extract All). ZIP ke andar se chalana nahi hai.
2. GitHub par PAT banao (Settings > Developer settings > Personal access tokens > Tokens (classic)):
   'repo' aur 'workflow' DONO tick karo. Token copy kar lo.
3. Extract hue folder me "UPLOAD_KARO.bat" par double-click karo.
   (Na chale to us folder me Command Prompt kholo aur likho: python upload_to_github.py)
4. GitHub username aur PAT daalo (PAT paste karne par screen par kuch nahi dikhega - normal hai).
5. Script files upload karegi, APK build karwayegi (5-10 min) aur
   is folder me QuizBot.apk save kar degi. Isse phone me bhejkar install karo.
